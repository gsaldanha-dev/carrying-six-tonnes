# Carrying six tonnes

Form and function in the elephant skeleton — an interactive comparative-anatomy slide.

Eleven structures of *Loxodonta africana*, each one set against the same structure in
*Homo sapiens*, built as a single page with a procedural 3D skeleton you can turn and zoom.

**Presenter mode** plays a three-minute guided run: six beats, the camera moving by itself
through each structure, with a timer and a check for the three strands of the analysis
(structure → function → human comparison).

- `index.html` — the page, the panel copy and the presenter logic
- `data.js` — the eleven structures: camera positions, labels, notes, sources
- `build3d.js` — the procedural skeletons

three.js r160 is loaded from a CDN. Add `?full=1` to the URL to show the full credit line.

Sources are listed in the panel on every structure.
